# X30 documentation

Five documents, written in LaTeX ([`latex/`](latex)), committed as PDFs ([`pdf/`](pdf)) and published
as a website with one page per chapter: **https://darmawanrobotics.github.io/x30_ros/**.

| Document | For | PDF |
|---|---|---|
| **Installation Guide** | from nothing to the first patrol: the Mac, the robot without internet, its two hosts as services, the handheld, NETRA and its license | [X30-Installation-Guide.pdf](pdf/X30-Installation-Guide.pdf) |
| **User Manual** (A5) | the operators: safety, the H12 and its app, routes, patrols, inspection, the recorder, NETRA | [X30-User-Manual.pdf](pdf/X30-User-Manual.pdf) |
| **Tuning Guide** | the models behind every setting, how to measure them, the complete parameter reference | [X30-Tuning-Guide.pdf](pdf/X30-Tuning-Guide.pdf) |
| **Architecture & Technical Reference** | hosts, packages, data flow, the safety chain, the protocols, operations, tests | [X30-Architecture.pdf](pdf/X30-Architecture.pdf) |
| **Site Acceptance Test** | the tests, criteria and sign-off that hand an X30 over to a substation | [X30-Site-Acceptance-Test.pdf](pdf/X30-Site-Acceptance-Test.pdf) |

## Build

```bash
make -C docs pdf          # the figures and the five documents, copied to docs/pdf (commit them)
make -C docs reference    # the Tuning Guide's parameter tables from the code (after a config change)
make -C docs site         # the website in docs/site/.vitepress/dist (site/README.md)
```

Needs XeLaTeX and latexmk with TeX Live 2022 or newer, pdftocairo, pandoc 3, Node 20. On Ubuntu:

```bash
sudo apt install texlive-xetex texlive-latex-recommended texlive-latex-extra texlive-pictures \
  texlive-science texlive-fonts-recommended latexmk fonts-dejavu-core fonts-dejavu-extra \
  fonts-lmodern pandoc poppler-utils librsvg2-bin
```

## Sources

| Path | Holds |
|---|---|
| `latex/x30doc.cls` | the documents' class: EZRA's look (Barlow, the cover, the boxes), A4 or `a5` |
| `latex/<document>.tex`, `latex/<document>/` | each document and its chapters |
| `latex/figures/` | the figures (TikZ, pgfplots), compiled to PDF for the documents and SVG for the site |
| `latex/generated/` | the parameter tables, generated by `tools/params.py` from the code: do not edit |
| `tools/tex2md.py`, `tools/tex2md.lua` | the chapters to website pages (pandoc) |
| `site/` | the website (VitePress) |

The workflow [`.github/workflows/docs.yml`](../.github/workflows/docs.yml) checks that the parameter
tables match the code, builds the PDFs and the site on every pull request, and publishes the site
from `main`.
