\chapter{Parameter reference}
\label{ch:t-reference}

Every parameter of every node, generated from the configuration declarations of the sources
(\file{docs/tools/params.py}): name, default, unit, accepted range and meaning. The default is
the value in the code; the X30's YAML files set some of them for the robot (the profile in
\file{x30_bringup/config/robot.yaml}, every node in its package's \file{config/}), and those
files win. \readonlynote
