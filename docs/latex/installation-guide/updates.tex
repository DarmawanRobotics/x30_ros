\chapter{Updates and backups}
\label{ch:i-updates}

\section{A new version of the stack}

\begin{lstlisting}[language=bash]
# on the Mac, online
cd ~/x30/x30_ros && git pull
GIT_CONFIG_COUNT=1 GIT_CONFIG_KEY_0=url.git@github.com:.insteadOf \
  GIT_CONFIG_VALUE_0=https://github.com/ \
  bash tools/pack_sources.sh ~/x30/x30_sources.tar.gz
# at the robot
scp ~/x30/x30_sources.tar.gz ysc@192.168.1.106:~/   # and .105
ssh ysc@192.168.1.106
rm -rf ~/x30_ws/src && tar -xzf ~/x30_sources.tar.gz -C ~/x30_ws
cd ~/x30_ws && catkin_make -DCATKIN_ENABLE_TESTING=OFF -DCMAKE_BUILD_TYPE=Release
sudo systemctl restart x30-navigation
\end{lstlisting}

Run \file{check_deps.sh} again after an update: a new version may need a new package. The
\code{CHANGELOG.md} of x30\_ros says what changed and whether a settings file needs a new line.

\section{A new app}

\begin{lstlisting}[language=bash]
gh release download -R DarmawanRobotics/X30Controller -p 'x30-controller-*.apk' --clobber
adb install -r x30-controller-*.apk
\end{lstlisting}

\section{A new NETRA}

\begin{lstlisting}[language=bash]
cd ~/x30/Netra && git pull && git submodule update --init --recursive
scripts/local.sh up        # online: rebuilds what changed
\end{lstlisting}

  \textbf{Where} & \textbf{What} \\

  NETRA & \cmd{scripts/local.sh export}: database, photos and plans in one file \\
  \bottomrule
\end{tabularx}
\end{center}
