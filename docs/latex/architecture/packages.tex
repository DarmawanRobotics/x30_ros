\section{Inside a package}

\begin{lstlisting}
x30_<name>/
  src/x30_<name>/core/      the algorithms, pure Python, no ROS (tested alone)
  src/x30_<name>/utils/     conversions between messages and the core's types
  src/x30_<name>/*_node.py  the nodes: parameters, topics, services around the core
  config/*.yaml             the X30's settings
  launch/*.launch
  test/unit/                tests of the core (pytest, no ROS)
  test/ros/                 tests of the nodes on a ROS master (rostest)
  README.md
\end{lstlisting}
