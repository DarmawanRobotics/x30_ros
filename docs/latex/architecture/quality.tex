\section{CI}

GitHub Actions on every pull request and on \code{main}, in the \code{ros:noetic-ros-base}
container: the dependencies from the packages' manifests, \cmd{catkin_make} and every test with
its failures as annotations, the URDF checked, the shell scripts; a second job builds and tests
the NeuPAN controller in its environment. The documentation's workflow builds the PDFs and the
website from \file{docs/} and publishes the site on GitHub Pages.

\section{Versions}

One version for the whole stack, in every \file{package.xml} and in \file{CHANGELOG.md} (Keep a
Changelog, Semantic Versioning).
